# Introduction

This project is licensed under the terms of the MIT license.

This is a simple, hopefully educational attempt to build a HTTP server and client in C using the winsock library.

This project was created for the purposes of the NUS module EE4210 Network Protocols and Applications.

# Building

The preferred compilation environment is MSYS2, using a Makefile generated by `build.sh`.

Failing that, the build scripts must be run from a Visual Studio dev shell. `build.bat`, when run from such a shell, should build a Visual Studio project. Failing that, `build_raw.bat` from the dev shell should build the executables in the `bin` folder.

The builds have been tested with `gcc 9.3.0` and `MSVC 19.25.28612`.

However the executables are built, they may be run as standard command line applications.

# Usage

`server.exe` automatically starts hosting a server on port `33333` (configurable as a macro)

`client_p.exe` downloads 3 files (`a.jpg`, `b.mp3`, `c.txt`) to the `usr` folder over a persistent TCP connection, while `client_np.exe` does likewise over a non-persistent connection. Either `.exe` file can be executed with an integer as a command line argument. This integer will be interpreted as a `time_t` variable for the purpose of executing a conditional GET. Alternatively, the argument `now` will use the current time. In summary:

- Integer: Get the files if they have been modified after this Unix timestamp
- `now`: Get the files if they have been modified after the present moment
